Finding x- and y-Intercepts

Where a graph crosses the axes — for lines and parabolas

What Are Intercepts?

An intercept is a point where a graph crosses one of the axes. Every graph can have two kinds of intercepts:

x-intercept

The point where the graph crosses the x-axis. At every point on the x-axis, the height is zero, so:

y = 0

Written as an ordered pair: (a, 0)

y-intercept

The point where the graph crosses the y-axis. At every point on the y-axis, you haven't moved left or right at all, so:

x = 0

Written as an ordered pair: (0, b)

The key idea: to find an intercept, you simply substitute 0 for the other variable and solve. Substitute y = 0 to find the x-intercept. Substitute x = 0 to find the y-intercept.

Lines vs. Parabolas

A straight line (unless it's horizontal or vertical) crosses the x-axis exactly once and the y-axis exactly once.

A parabola always crosses the y-axis exactly once (parabolas pass the vertical line test), but it can cross the x-axis zero, one, or two times depending on whether the vertex sits above, on, or below the x-axis.

Tip: for a parabola, the number of x-intercepts is determined by the discriminant, b² − 4ac. If it's positive, there are two x-intercepts. If it's zero, there's exactly one (the vertex touches the x-axis). If it's negative, there are none — the parabola never crosses the x-axis. You'll see this live in the next tab!

Finding Intercepts Algebraically

To find intercepts without a graph, substitute 0 for the other variable and solve. Here are four worked examples.

Example 1: 2x + 3y = 12

x-intercept (set y = 0):  2x + 3(0) = 12 → 2x = 12 → x = 6
y-intercept (set x = 0):  2(0) + 3y = 12 → 3y = 12 → y = 4
x-intercept: (6, 0) y-intercept: (0, 4)

Example 2: y = −3x + 9

x-intercept (set y = 0):  0 = −3x + 9 → 3x = 9 → x = 3
y-intercept (set x = 0):  y = −3(0) + 9 → y = 9
x-intercept: (3, 0) y-intercept: (0, 9)

Example 3: 5x − 2y = −10

x-intercept (set y = 0):  5x − 2(0) = −10 → 5x = −10 → x = −2
y-intercept (set x = 0):  5(0) − 2y = −10 → −2y = −10 → y = 5
x-intercept: (-2, 0) y-intercept: (0, 5)

Example 4: x − 4y = 6  (an example with a fractional answer)

x-intercept (set y = 0):  x − 4(0) = 6 → x = 6
y-intercept (set x = 0):  0 − 4y = 6 → −4y = 6 → y = −1.5
x-intercept: (6, 0) y-intercept: (0, -1.5)
Intercepts don't have to be whole numbers — always simplify the fraction or decimal completely.

Practice (Self-Check, Not Graded)

Work these out on paper, then click Reveal Solution to check yourself.

Practice 1:  y = 2x + 6

x-intercept (y = 0): 0 = 2x + 6 → x = −3 → (-3, 0)
y-intercept (x = 0): y = 2(0) + 6 → y = 6 → (0, 6)

Practice 2:  4x − y = 8

x-intercept (y = 0): 4x − 0 = 8 → x = 2 → (2, 0)
y-intercept (x = 0): 4(0) − y = 8 → y = −8 → (0, -8)

Practice 3:  y = x² − 1  (a parabola — look for two x-intercepts)

x-intercepts (y = 0): 0 = x² − 1 → x² = 1 → x = 1 or x = −1 → (1, 0) and (-1, 0)
y-intercept (x = 0): y = 0² − 1 → y = −1 → (0, -1)

Practice 4:  y = x² + 2x + 1  (a parabola — how many x-intercepts does this one have?)

x-intercept (y = 0): 0 = x² + 2x + 1 = (x + 1)² → x = −1 (a repeated root) → only one x-intercept: (-1, 0)
y-intercept (x = 0): y = 0 + 0 + 1 → y = 1 → (0, 1)
This parabola's vertex sits exactly on the x-axis, so it touches but doesn't cross — giving exactly one x-intercept.
